Multivariate mapping

Showing more than one variable

Options to show two or more data variables:

  1. Facets (small multiples): one map per variable
  2. Multiple map variables: e.g. fill color for one variable, symbol size for another
  3. Multivariate map variables: one map variable encodes several data variables
    • bivariate choropleth: two variables → one fill color
    • RGB images: three bands → one color
    • glyphs: several variables → one small chart (session 6)

1. Facets

tm_shape(World) +
  tm_polygons(
    fill = c("gender", "inequality"),
    fill.legend = tm_legend("")) +
tm_crs("auto") +
tm_layout(panel.labels = c("Gender inequality", "Economic inequality"))

Easy to read per variable, but the reader has to compare the maps to see the relationship.

2. Multiple map variables

Multiple map variables: considerations

  • Each map variable has its own scale and legend
  • Combine map variables that are perceived separately: e.g. area fill + symbol size
  • Two color variables (polygon fill + symbol fill) compete for attention
  • Visual hierarchy: which variable should be read first?

Multiple data variables for one map variable

Specifying a vector of variables creates facets:

tm_polygons(fill = c("gender", "inequality"))

The function tm_vars() offers more options, including multivariate mapping:

tm_polygons(fill = tm_vars(c("gender", "inequality"), multivariate = TRUE))
tm_vars(12:18)            # facets for columns 12 to 18
tm_vars(n = 3)            # facets for the first 3 variables

Step 1: minimal example

How to read a bivariate choropleth

  • Each variable is classified into (usually) 3 classes
  • The 3 × 3 combinations each get a color from a 2D palette
  • The legend is a 3 × 3 grid: essential for reading the map
  • Diagonal: both variables low / both high → shows correlation
  • Off-diagonal corners: one high, the other low → shows exceptions

More than 3 × 3 classes is usually hard to read.

Flipping bivariate palettes

Prefix Meaning
"-" flip columns
"|" flip rows
"+" flip rows and columns
"//" flip diagonally
"\\" flip the other diagonal

Prefixes can be combined, e.g. "-//".

Note: the origin of a palette plotted with c4a_plot() is top left, but the origin of a bivariate legend in tmap is bottom left, so the diagonal prefixes need to be the other way round.

Palettes in tmap: tm_scale_bivariate()

Step 3: the individual scales

scale1 and scale2 define how each variable is classified:

tm_shape(World) +
  tm_polygons(
    fill = tm_vars(c("gender", "inequality"), multivariate = TRUE),
    fill.scale =
      tm_scale_bivariate(
        scale1 = tm_scale_intervals(style = "kmeans", n = 3, labels = c("L", "M", "H")),
        scale2 = tm_scale_intervals(style = "kmeans", n = 3, labels = c("L", "M", "H")),
        values = "bu_br_bivs")) +
tm_crs("auto")

Step 3: the individual scales

Choosing the class breaks

  • "quantile": each row and column of the legend holds (about) one third of the features
    • the marginal distributions are balanced, but the 9 cells are not
  • "kmeans", "fisher": natural groups in the data
  • "fixed" with meaningful breaks: e.g. policy thresholds, or the median / average
  • Check how many features fall in each cell: a chart helps (see below)

Step 4: the legend

Bivariate legend

tm_legend_bivariate() has all arguments of tm_legend(), plus:

  • xlab, ylab: axis labels
  • xlab.size, xlab.color, xlab.rot, xlab.fontface, … (and the same for ylab)

Tips:

  • Use short labels (L / M / H, or arrows) and explanatory axis titles
  • Place the legend where it can be read together with the map (inside the frame, in empty space)
  • Square legend items (item.width = item.height) and no rounding (item.r = 0) give a clean grid

How are the countries distributed?

Quantile classes balance each variable separately, but not the 9 combinations. To show the distribution, we can make our own legend, as a ggplot2 chart shown with tm_inset() (session 10).

Breaks and palette

First, fixed breaks and the palette as a 3 × 3 matrix, so that we know exactly which class and color each country gets:

b1 = quantile(World$gender, probs = seq(0, 1, length.out = 4), na.rm = TRUE)
b2 = quantile(World$inequality, probs = seq(0, 1, length.out = 4), na.rm = TRUE)
pal = c4a("bu_br_bivs", n = 3, m = 3)
pal
     [,1]      [,2]      [,3]     
[1,] "#F1F1F1" "#E4C2A9" "#B98049"
[2,] "#AECBEA" "#A3A3A3" "#77583F"
[3,] "#4992C8" "#41617D" "#343434"

In the tmap legend, row 1 of this matrix is the bottom row (low economic inequality) and column 1 the left column (low gender inequality).

Counting the classes

d = sf::st_drop_geometry(World)
d = d[!is.na(d$gender) & !is.na(d$inequality), ]
d$c1 = cut(d$gender, b1, include.lowest = TRUE, right = FALSE)  # closed on the left
d$c2 = cut(d$inequality, b2, include.lowest = TRUE, right = FALSE)

tab = as.data.frame(table(c1 = as.integer(d$c1), c2 = as.integer(d$c2)))
tab$fill = pal[cbind(as.integer(tab$c2), as.integer(tab$c1))]
tab$text_col = ifelse(as.integer(tab$c1) + as.integer(tab$c2) >= 5, "white", "black")

A scatter plot legend

The legend can also show the individual countries: a scatter plot on top of the 9 colored classes.

rects = expand.grid(i = 1:3, j = 1:3)   # i: row (economic), j: column (gender)
rects$xmin = b1[rects$j]
rects$xmax = b1[rects$j + 1]
rects$ymin = b2[rects$i]
rects$ymax = b2[rects$i + 1]
rects$fill = pal[cbind(rects$i, rects$j)]

g_sc = ggplot() +
  geom_rect(data = rects, aes(xmin = xmin, xmax = xmax, ymin = ymin, ymax = ymax, fill = fill)) +
  geom_point(data = d, aes(gender, inequality), 
    shape = 21, fill = "black", colour = "white", size = 1.5, stroke = 0.3) +
  scale_fill_identity() +
  labs(x = "Gender inequality", y = "Economic inequality") +
  theme_minimal()

When to use a bivariate choropleth

✅ Good for:

  • showing the spatial relationship between two (related) variables
  • highlighting areas where the relationship breaks down

🚫 Less suited for:

  • audiences who are not used to it (always explain the legend)
  • reading exact values of either variable (use facets instead)
  • more than 3 × 3 classes

Recap

  • Several variables: facets, multiple map variables, or a multivariate map variable
  • Facets: fill = c(...), tm_facets(), or one variable with a list of scales
  • value.neutral and tm_legend_combine() for multiple legends
  • tm_vars(..., multivariate = TRUE) turns several data variables into one map variable
  • Bivariate choropleth: tm_scale_bivariate() (with scale1, scale2, values) and tm_legend_bivariate()
  • Bivariate palettes from cols4all: "bivs", "bivc", "bivd", "bivg"; flip with prefixes
  • Keep it at 3 × 3 classes, and make the legend prominent
  • Further reading: bivariate choropleth | multivariate | charts
